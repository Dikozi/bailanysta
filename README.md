# My Assist — промо-сайт

Лендинг личного ИИ-ассистента в Telegram: он записывает дела из текста и голоса, ставит их в Google Календарь, напоминает и подводит итоги. Сайт продаёт персональную настройку ассистента под клиента.

## Стек

- Next.js 16 (App Router), статическая сборка
- Tailwind CSS 4, токены в `src/app/globals.css`
- Шрифты Onest и JetBrains Mono подключены локально через `@fontsource-variable`, без запросов к Google Fonts
- Иконки: `lucide-react`; значки Telegram и Instagram и временный логотип нарисованы вручную в `src/components/brand.tsx`

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка
npm run lint && npm run typecheck
```

Деплой: импортировать репозиторий в Vercel, настройки по умолчанию.

## Где что менять

| Что | Где |
| --- | --- |
| Ссылка на Telegram, Instagram, цена | `src/lib/site.ts` |
| Демо на первом экране (сценарии, тексты сообщений) | `src/components/demo/hero-demo.tsx` |
| Секции страницы | `src/components/sections/` |
| Цвета, шрифты, анимации | `src/app/globals.css` |
| Факты о продукте для дизайна и текстов | `PRODUCT.md` |

## Честность текстов

Все переписки на странице — демонстрация по реальным шаблонам сообщений бота, это подписано на странице. На сайте нет выдуманных отзывов, цифр пользователей и сравнений с конкурентами. Если эти данные появятся, их можно добавить, но только настоящие.

## Скиллы для дизайна

В `.claude/skills/` установлены скиллы impeccable, taste-skill и набор Эмиля Ковальского. Направление дизайна и договорённости записаны в `PRODUCT.md` и `.impeccable/`.
